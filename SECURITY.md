# Security policy

Security fixes target the current `main` branch. Other branches and historical
commits do not receive separate security updates.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/michaelcrosato/gta4-gpt61/security/advisories/new).
Include the affected commit, steps to reproduce, expected impact, and any
suggested fix. Share only the information needed to reproduce the issue; redact
credentials and personal data.

Keep vulnerability details private while the maintainer investigates and
coordinates a fix. Use public issues for bugs that do not expose a security risk.
